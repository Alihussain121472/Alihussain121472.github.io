## 🌌 Overview

**araknet.tech** is designed not as a static digital resume, but as a sleek, futuristic product command center. Built from scratch with vanilla web standards for instant zero-latency loading, high responsiveness, and cinematic aesthetic.

### ✨ Key Features

1. **Interactive Neural Particle Network**: Dynamic background canvas simulating neural weights and connections with real-time mouse interaction.
2. **Dynamic Certification Hub & Manager**:
   - Accredited credentials showcase (Cisco Networking Academy, Harvard CS50 Python, AIEYS).
   - **Interactive Lightbox**: Enlarge any certificate in full-screen high-resolution with direct verification links.
   - **Add & Remove Certificates In-Browser**: Upload new certificate pictures directly from your device (stored in `localStorage` via Base64 data encoding) or add via image URL without touching code.
   - **JSON Export & Backup**: One-click export of your certificates array to commit permanently to the repository whenever you choose.
3. **Flagship & Vertical AI Projects**:
   - **NovaBrief Tech** (Featured SaaS at [novabrief.tech](https://www.novabrief.tech)): Daily student intelligence digests powered by Llama 3.3 and Groq API.
   - **NovaBrief Email Reply Agent**: Context-aware n8n automation agent.
   - **DHA Multan Real Estate AI Agent**: Vertical SaaS property advisor.
   - **Khidmat AI**: Civic assistance platform built with Django.
   - **Autonomous SEO Agent**: Automated keyword and E-E-A-T entity pipeline.
4. **Interactive Curriculum Vitae (CV)**: Clean visual qualification breakdown with one-click direct PDF download (`Syed_Ali_Hussain_Resume.pdf`) and fullscreen preview modal.
5. **Command Palette (`Ctrl + K`)**: Futuristic terminal navigation tool for developers and recruiters.
6. **One-Click Email Copy & Toast Feedback**: Direct clipboard action with instant visual confirmation.
7. **Production SEO & OpenGraph**: Ready for sharing on LinkedIn, Twitter/X, and WhatsApp with custom meta tags and rich snippets.

## 🚀 How to Deploy on `araknet.tech`

### Option 1: Cloudflare Pages (Recommended - Fastest & Free SSL)
1. Push this repository to your GitHub account (`Alihussain121472`).
2. Log in to [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
3. Select this repository. Build settings:
   - Framework preset: `None`
   - Build command: *(leave empty)*
   - Build output directory: `.` (root directory)
4. Click **Deploy**.
5. Under **Custom Domains**, click **Set up a custom domain**, enter `araknet.tech`, and follow the DNS prompts. SSL is automatically provisioned!

### Option 2: Vercel
1. Import repository on [Vercel](https://vercel.com).
2. Root directory: `./`.
3. Add custom domain `araknet.tech` in project settings.

### Option 3: cPanel / Traditional Hosting
1. Zip all files in this directory.
2. Upload and extract inside your `public_html` directory via cPanel File Manager.
3. Verify SSL certificate is enabled in cPanel.
