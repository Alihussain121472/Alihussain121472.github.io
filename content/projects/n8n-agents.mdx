## Context

A pair of automated **AI agents** built with n8n to run daily content publishing and inbox replies for NovaBrief Tech, a daily AI briefing for students.

## Core AI Agents

1. **Daily LinkedIn Posting Agent**: Reads the latest NovaBrief Tech edition, formats a concise summary with an LLM node, and schedules the daily LinkedIn post.
2. **Email Reply Agent**: Parses incoming reader questions and drafts context-aware email replies inside n8n.
