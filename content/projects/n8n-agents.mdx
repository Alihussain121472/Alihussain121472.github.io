## Overview

A suite of production **n8n automation agents** built to handle daily content distribution and communication workflows for NovaBrief Tech.

## Core Agents

1. **Daily LinkedIn Posting Agent**: Automatically drafts, formats, and schedules daily intelligence highlights for LinkedIn from NovaBrief Tech briefings.
2. **Email Reply Agent**: Parses incoming inquiries and drafts context-aware responses using LLM workflows orchestrated inside n8n.
