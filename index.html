NovaBrief Tech

Live

A daily morning digest that delivers top AI news and student programs in one place.

Problem

AI news and student programs are published across many sources, making it hard to keep up consistently.

Solution & Architecture

A Python and Flask backend collects daily news and student programs. It uses a fast AI model to write brief summaries, then emails a morning digest to subscribers.

Key Achievements

  • Scheduled digest and program-notification jobs run at configured times.
  • PostgreSQL stores the collected items and delivery records.
  • Email delivery supports configured Resend or SMTP credentials.

Araknet.tech Business Agent

Live

Find local businesses, check their web presence, and draft outreach messages to follow up.

Problem

Finding local clients across multiple websites takes too much time. It is hard to compare leads and track who to contact next.

How it works

Choose a city and industry to search Google Places, SerpAPI, or OpenStreetMap. Review the listings, add notes and tags, and draft an editable proposal for each lead. Listing details and suggestions need human review.

What it includes

  • Pulls company info from three map services, with a smart backup if one is down.
  • Tracks lead status, notes, and tags, with CSV and JSON export.
  • Builds ready-to-edit email drafts from templates. You review and send every note yourself.
Next.js React TypeScript MongoDB Atlas SerpAPI Google Places API OpenStreetMap

MY Mentore

Desktop app

A personal study agent that helps learners plan what to study and practice each day.

Problem

When lessons, quizzes, and projects live in separate tools, it can be hard to know what to work on next.

How it works

Learners set a goal and choose how much time they have to study. MY Mentore brings lessons, quizzes, and project work into one Windows app, with optional Gemini help for explanations and writing.

What it includes

  • Study plans connect goals to lessons, quizzes, and project tasks.
  • The mentor workspace and study hub are part of the same Windows app.
  • This is a desktop app. There is no public web version or code repository yet.
